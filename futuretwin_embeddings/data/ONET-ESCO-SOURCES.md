# Official occupational task and mapping snapshots

These are source datasets, not fictional tasks generated by FutureTwin.
Snapshots were downloaded from the publishers on **2026-10-23**. The gzip
containers are lossless packaging; the CSV source content was not edited.

## O*NET® 31.0 Task Statements

- Publisher: U.S. Department of Labor, Employment and Training Administration.
- Data dictionary: <https://www.onetcenter.org/dictionary/31.0/csv/task_statements.html>
- Original CSV: <https://www.onetcenter.org/dl_files/database/db_31_0_csv/task_statements.csv>
- Local asset: `onet_task_statements_31_0.csv.gz`
- SHA-256 of local gzip: `489eac28babdcb32a79232e08dcc0612bbf6db3c047c2ea512bbd7348b65e277`
- 18,838 source rows across 923 distinct O*NET-SOC occupation codes.
- Fields retained: O*NET-SOC code, occupation title, Task ID, task statement, task
  type, incumbents responding, row update date and domain source.
- Both core and supplemental task records are retained. All task records are
  equally counted; no work-time or importance weights have been invented.

## European Commission ESCO–O*NET occupation crosswalk

- Publisher: ESCO Secretariat in collaboration with U.S. DOL/ETA.
- Official download page:
  <https://esco.ec.europa.eu/en/use-esco/other-crosswalks>
- Original CSV:
  <https://esco.ec.europa.eu/system/files/2023-08/ONET_%28Occupations%29_0_updated.csv>
- Local asset: `esco_onet_occupations_v1_2022_09.csv.gz`
- SHA-256 of local gzip: `109b06beecbf61237d254f24a1a2dcaf9c815dc72163dfbc00d66f7c38aad78f`
- Published metadata: mapping version 1, September 2022; O*NET-SOC 2019 to ESCO
  v1.1.0. The downloadable file was updated in August 2023.
- 4,253 published mapping edges. Original relation types remain unchanged:
  `exactMatch`, `broadMatch`, `narrowMatch`, `closeMatch` and `exactISCO`.
- The [published methodology](https://esco.ec.europa.eu/en/about-esco/data-science-and-esco/crosswalk-between-esco-and-onet)
  describes semantic candidate generation followed by human validation and
  quality assurance. FutureTwin does not recreate or replace this mapping using
  title similarity.

### Interpretation limits

Only published `exactMatch` edges contribute to the primary ESCO occupation
distribution. Other relationships remain separately inspectable possible source
task sets. ISCO-group links are retained but not expanded into unverified ESCO
occupation equivalences. Historical ESCO URIs missing from the current local
catalog are not silently repaired using title similarity.

The source inventories are U.S. occupational task descriptions. Their coverage
is not a verified inventory of every task performed in Malaysian or other labor
markets. A 100% classification-coverage figure only means all linked source
records were classified.

The checkpoint contains E0/E1/E2 code mappings but not the original training
dataset or semantic rubric. Combined exposure statistics remain disabled.
